Solmar Bay — Neon Streets: an original open-world crime game in the browser, where Milo Cruz takes three jobs across a sun-soaked coastal city, steals cars, outruns the police and pulls off one big score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move or drive, E to steal or enter a car, click or F to shoot, drag the mouse to look around, P to pause.
